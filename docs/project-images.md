## Pomerium Space 촬영과 배치

- 메인 페이지 전체를 직접 개발했다는 사용자 확인을 역할과 경력 설명에 반영했습니다.
- 데스크톱은 헤더·히어로, 코인 소개, 에코시스템, 커뮤니티, 뉴스, 거래소 안내, 스테이킹, 토큰·NFT, 서비스, 파트너, CTA·푸터의 11개 화면을 촬영했습니다.
- 라이트·다크 비교는 사이트 하단의 실제 테마 전환 버튼을 사용해 동일한 코인 소개·커뮤니티 섹션을 촬영한 뒤 좌우로 배치했습니다. CSS 재색칠이나 테마 재현을 하지 않았습니다.
- 모바일은 390×844 뷰포트에서 메인, 코인 소개, 에코시스템, 커뮤니티, 뉴스, 토큰·NFT, 서비스, 파트너를 촬영했습니다. 네 장씩 두 개의 가로 이미지로 묶었습니다.
- 비교 이미지에는 원본 화면 바깥에 모드·섹션 라벨과 여백만 추가했습니다.
- 데스크톱 메인·푸터는 1440×1000, 섹션은 1440×1600 뷰포트에서 영역 캡처했습니다. 첫 방문 안내 팝업을 닫고 실제 슬라이더 일시정지를 사용했습니다.
- 현재 서비스 화면으로, 재직 당시의 화면과 다를 수 있습니다.

제공된 슬라이드에는 SINGAL·Zone Editor·Readly·ASH//ERROR 화면이 없어 해당 프로젝트에 이미지를 추가하지 않았습니다.
